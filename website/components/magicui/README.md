| Component            | Use                                                                    |
| -------------------- | ---------------------------------------------------------------------- |
| MagicCard            | Pointer-following light on board tiles and example cards               |
| AnimatedList         | Streaming events arriving one after another in the computation model   |
| BlurFade             | Entrance of section headings; content stays visible without JavaScript |
| AnimatedThemeToggler | Persisted light/dark choice with a circular transition                 |

The MIT license preserves the upstream copyright. Local adaptations use Phosphor icons, semantic colors, and reduced-motion handling. Each of these animations runs once. Reduced motion disables the theme reveal, the pointer-driven light and the list and entrance motion.
