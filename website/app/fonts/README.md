# Geist fonts

The Latin variable WOFF2 files come from the bundled Geist fonts in Next.js 15.5.9 (`next/dist/next-devtools/server/font/`). They are stored locally so development and production builds do not need Google Fonts.

Geist and Geist Mono are copyright 2023 Vercel, in collaboration with basement.studio. The included `OFL.txt` contains the upstream SIL Open Font License 1.1 from https://github.com/vercel/geist-font/blob/main/LICENSE.txt.
